## Tic-Tac-Toe (JavaScript)

A browser-based Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## Features
- Two-player gameplay
- Turn management for X and O
- Game state tracking
- Win and draw detection across rows, columns, and diagonals
- Automatic game reset after a win or draw

## Technologies
- HTML
- CSS
- JavaScript

## How It Works
Players take turns placing X and O on the board by clicking on an empty cell. 

The JavaScript tracks the current player and number of moves, updates the game status, and checks for winning combinations after each move.

If a player completes a row, column, or diagonal, the game declares them the winner and resets the board. If all nine cells are filled without a winner, the game is declared a draw and the board resets.

## Running the Project
1. Download or clone the repository
2. Open `board.html` in a web browser
3. Click the cells on the board to play.
